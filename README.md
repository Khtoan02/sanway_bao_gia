# SANWAY - Hệ Thống Quản Lý & Xuất Báo Giá PCCC Chuyên Nghiệp

Hệ thống tạo và xuất báo giá tự động theo đúng bộ nhận diện thương hiệu **SANWAY** (*Cho mỗi bước tiến thêm vững vàng*).

## 🚀 Tính Năng Chính
- **Chuẩn Brand Guidelines SANWAY**:
  - Tông màu chủ đạo: Đỏ PCCC (`#D62828`), Xám đen kim loại (`#2F3742`), Xám trung tính (`#6B737D`), Nền sáng (`#F5F7FA`).
  - Tích hợp Logo SANWAY chính thức và con dấu mộc đỏ.
- **Soạn thảo báo giá linh hoạt**:
  - Nhập thông tin khách hàng, công trình, ngày lập, người ký.
  - Tùy chỉnh thuế suất VAT (%) tùy ý.
  - Quản lý 47 hạng mục sản phẩm/vật tư PCCC chi tiết từ hồ sơ gốc.
  - Tích chọn/bỏ chọn từng mục, sửa khối lượng và đơn giá trực tiếp trên bảng.
  - Thêm hạng mục vật tư mới hoặc xóa bớt.
- **Xem trước & Xuất PDF chuẩn khổ A4**:
  - Bố cục bảng báo giá tự động gom nhóm hệ thống khoa học.
  - Tự động tính tổng tiền và đọc số thành chữ tiếng Việt chuẩn tài chính.
  - Tối ưu CSS `@media print` in ấn và lưu file PDF sắc nét chuẩn khổ giấy A4 Portrait.

## 💻 Hướng Dẫn Sử Dụng
Mở trực tiếp file `index.html` bằng trình duyệt hoặc khởi chạy qua server:
```bash
python3 -m http.server 3000
```
Truy cập: `http://localhost:3000`
